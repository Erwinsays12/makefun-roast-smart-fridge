# The Fridge Keeps Receipts

A one-line roast of the smart fridge, entered in
[Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/c/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9)
on make.fun.

## The line

> My smart fridge logs every 2 a.m. snack, then greets me with 'Welcome back!' like it isn't keeping receipts for my doctor.

## How it works

`main.py` writes that single line (122 characters, under the 160-character
limit) to `/output/entry.txt`. Nothing to install, no network, no input:
the roast is fixed and deterministic, so every run writes the same text.

```sh
python3 main.py
```
